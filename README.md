# Liuli Society Website

GitHub-ready React project for a nonprofit institutional website.

## Tech
- Vite
- React
- React Router (HashRouter)
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
This project uses `base: './'` in `vite.config.js`, so it is suitable for static hosting.

## Project structure
```text
src/
  assets/
  components/
  pages/
  App.jsx
  main.jsx
```

## Notes
- Images are already included in `src/assets`
- This website is structured for nonprofit positioning, not e-commerce
